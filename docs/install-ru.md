# CoinsPay для LiteCart: установка

Модуль принимает оплату криптовалютой через CoinsPay: покупатель выбирает монету и сеть на странице
оплаты CoinsPay, а заказ сам отмечается оплаченным, когда платёж поступит. Деньги сразу уходят на
ваши кошельки.

Работает на LiteCart 2.5–2.7. Нужен аккаунт CoinsPay с магазином.

## Установка

1. Скопируйте содержимое папки `public_html` из архива в корневую папку магазина (там, где лежит
   `index.php`), сохраняя папки. Ни один файл LiteCart не заменяется.
2. В админке откройте «Модули» → «Оплата», найдите CoinsPay, нажмите «Установить», затем «Сохранить».

Модуль добавит два статуса заказа: «Ожидает криптоплатежа» (заказ ждёт оплаты, товары
зарезервированы на складе) и «Проверка криптоплатежа» (заказ отложен, решение за вами). Ещё он
добавит задачу «CoinsPay» в «Модули» → «Задачи»: она проверяет открытые счета, если вебхук не дошёл.

## Подключение

«Модули» → «Оплата» → CoinsPay. Панель вверху страницы показывает состояние модуля.

1. В кабинете CoinsPay откройте свой магазин.
2. В разделе «Ключи API» выпустите ключ с доступом **«Только счета»** и вставьте его в поле
   «Ключ API». Модулю больше ничего не нужно, а таким ключом нельзя вывести деньги.
3. Поле «Адрес API» оставьте пустым: тогда модуль использует `https://coinspay.app/api/v1`.
4. В разделе «Вебхук» укажите адрес, который показывает панель, сохраните и скопируйте секрет
   `whsec_…` в поле «Секрет вебхука».
5. Сохраните. Панель проверит подключение и покажет название вашего магазина CoinsPay и режим.
6. Нажмите в кабинете «Отправить тестовое событие»: панель покажет, когда оно пришло.

## Статусы заказа

Каждое событие счёта что-то делает с заказом, а поля «Заказ оформлен…», «Оплачен»… выбирают статус:

| Событие счёта | Статус по умолчанию |
|---|---|
| Заказ оформлен, ждём оплату | Ожидает криптоплатежа |
| Платёж в пути, частичная оплата | не меняется (только комментарий) |
| Оплачен (вовремя, поздно, с переплатой, отмечен вручную) | первый ваш статус в состоянии Processing; записываются дата оплаты и транзакция |
| Истёк без оплаты, счёт отменён | Cancelled: резерв товаров снимается |
| Сумма не совпадает, оплачен отменённый заказ, тестовая оплата не от тестового покупателя, истёк или отменён частично оплаченный | Проверка криптоплатежа |

Пустое поле статуса оставляет статус заказа прежним и пишет только комментарий; для «Оплачен после
истечения счёта» и похожих оно значит «как у события „Оплачен“». К каждому событию в заказ пишется
комментарий с суммами, монетами и хешами транзакций, покупатель его не видит.

Когда вы переводите заказ в один из «Статусов отмены заказа», модуль отменяет его открытый счёт при
следующем запуске задачи «CoinsPay» (с cron — каждые 5 минут, без него — примерно раз в час), и
покупатель больше не сможет его оплатить.

## Тестовый режим

С тестовым ключом (`cpk_test_…`) счета оплачиваются кнопкой на странице оплаты, монеты не
переводятся. По умолчанию способ оплаты тогда виден только тестовому покупателю: откройте магазин по
ссылке «Открыть магазин как тестовый покупатель» из панели. Ссылка действует сутки в том браузере,
где её открыли. Тестовая оплата завершает только заказы тестового покупателя.

## Если вебхуки не доходят

Задача «CoinsPay» спрашивает CoinsPay об открытых счетах. Без cron LiteCart запускает свои задачи
от посещений сайта примерно раз в час. Чтобы проверять каждые 5 минут, добавьте адрес для cron из
панели в cron хостинга.

## Полезно знать

- Заказ сохраняется до оплаты. Если покупатель вернётся на страницу оформления и подтвердит заказ
  ещё раз, LiteCart создаст новый заказ; неоплаченный отменится, когда истечёт его счёт.
- Письмо о заказе LiteCart отправляет, когда покупатель возвращается в том браузере, где оформлял
  заказ. Чтобы покупатель получал письмо и при оплате, включите «Уведомлять» у вашего статуса оплаты.
- Покупатель, закрывший страницу оплаты, может оплатить позже: пока счёт открыт, на странице
  «Заказ оформлен» есть кнопка «Перейти к оплате».
- Счёт выставляется в валюте заказа, если CoinsPay её принимает, иначе — в валюте магазина.
- Журнал — `logs/coinspay.log`. Ошибки пишутся всегда, ключи и секреты — никогда.
